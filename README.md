MockAI Studio is a zero-backend prototyping tool that instantly turns natural language prompts into live, working REST endpoints and copy-paste-ready frontend snippets.

Tech Stack
Language / Runtime: TypeScript, Node.js (server.ts), Vite

Frontend: React / HTML5 (src/, index.html)

Build & Config: Vite, Tailwind/CSS, TypeScript

Getting Started
Clone the repository:

Bash
git clone https://github.com/zeeshanriaz050-afk/mockai-generator-.git
cd mockai-generator-
Install dependencies:

Bash
npm install
Configure environment variables:
Copy .env.example to .env and fill in your configuration keys:

Bash
cp .env.example .env
Run the development server:

Bash
npm run dev
